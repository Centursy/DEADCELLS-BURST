# DEADCELLS BURST

死亡细胞大作战！32 张地图和原版地图 Boss，以回合制战斗向玩家和 Boss 发起挑战。

这是一个面向 Koishi 和 QQ 群聊机器人的《死亡细胞》风格小游戏插件，包含地图探索、细胞成长、玩家对战、装备、护符、共享 Boss 讨伐和图片化输出。

## 安装

在 Koishi 项目中安装插件：

```bash
npm install koishi-plugin-deadcells-burst
```

在 Koishi 控制台中启用 `deadcells-burst`。插件需要 `database` 服务；如果希望输出图片，请同时启用 `puppeteer` 插件。

基本依赖：

- Koishi `4.18.0` 或更高版本
- Koishi Database
- Puppeteer（可选，图片渲染需要）

没有安装 Puppeteer 时，游戏仍可运行，会自动回退为文字输出。

## 指令

默认指令如下。Koishi 的全局命令前缀以实际配置为准。

| 指令 | 作用 |
| --- | --- |
| `deadcells` | 创建角色，或查看个人战斗名片和当前状态 |
| `修炼` | 开始或查看持久化派遣探索 |
| `boss细胞` | 消耗当前库存细胞提升细胞等级 |
| `对战 @用户` | 与另一名玩家进行自动回合制决斗 |
| `护符炼化` | 消耗细胞生成一个随机护符 |
| `护符炼化 3` | 一次生成 3 个护符候选，选择后确认替换 |
| `锻造装备` | 消耗细胞生成一组三件随机装备 |
| `锻造装备 3` | 一次生成 3 组装备，共 9 个选项 |
| `boss讨伐` | 参加今日全服共享 Boss 讨伐 |

指令名称和主要数值都可以在 Koishi 配置中调整。

## 游戏系统

### 角色与细胞

玩家拥有细胞、细胞等级、武器、副手、两个道具槽和一个护符。细胞等级通过消耗当前库存细胞提升，并会累计增加生命、攻击和暴击率；等级倍率最高为 5 倍。

战斗名片和个人页面会展示当前属性、装备、道具、护符词条、对战次数和胜率。

### 派遣探索

`修炼` 使用持久化派遣任务推进地图，每张地图默认约 10 分钟自动结算。任务状态保存在数据库中，Koishi 重启后会继续恢复。

开始探索时可以选择策略：

- 更多细胞：地图和 Boss 奖励乘以 1.5。
- 更深层数：进入下一张地图的概率从 80% 提高到 90%，上限为 90%。

每天最多结算 3 次，按东八区 00:00 重置。地图为分支结构，区域 Boss 只有在击败并成功进入下一张地图后才算通过。探索完成后机器人会在原群中 @ 发起者并发送结算图片。

### 玩家对战

玩家之间进行自动回合制战斗。武器技能、暴击、盾牌格挡、道具、副手冷却、异常状态和保命效果都会影响战斗过程。

胜者可以获得：

- 战败者当前细胞的 20%。
- 额外 1000 个细胞，该奖励会受到贪婪词条影响。
- 按概率掉落的装备或特殊复制效果。

对战默认冷却 60 秒。非盾牌副手的使用会独立占用一个行动回合，并拥有 3 回合冷却；盾牌保留格挡和对应特殊效果。

### 装备与护符

装备分为武器、副手和道具。装备可以重复获得，没有独立背包；替换后想再次获得旧装备，需要重新刷取。

护符拥有 0～2 个词条。词条会影响攻击、暴击、先攻、细胞倍率、保命、异常状态、Boss 伤害、反伤和暴击倍率等效果。

批量锻造规则：

- 次数范围为 1～5。
- 每次锻造生成 3 件组内不重复装备。
- 多次锻造时不同组之间允许出现重复装备。
- 费用按次数累计，展示所有选项并使用连续编号选择。

批量护符炼化规则：

- 次数范围为 1～5。
- 每次独立生成一个随机护符，候选之间允许重复。
- 费用按次数累计。
- 先选择候选护符，再回复 `y` 确认替换当前护符。

### 每日共享 Boss

`boss讨伐` 每天生成一个全服共享 Boss，所有群共享同一个生命池和讨伐排行榜。Boss 从非最终 Boss 中等概率随机选择，并随机生成难度和生命值。

Boss 分为三档：

| 难度 | 生命值 | 攻击倍率 | 奖励倍率 |
| --- | ---: | ---: | ---: |
| 普通 | 2000～12000 | 1 | 1 |
| 历战 | 23000～31000 | 1.5 | 2 |
| 历战王 | 35000～50000 | 2 | 3 |

Boss 基础攻击力为 30，每 3 回合攻击一次，暴击率为 50%。每名玩家独立拥有 10 分钟讨伐冷却。每次奖励按实际削减的生命值计算，并叠加难度、细胞等级和贪婪倍率；超额伤害不会重复计入。

最后一击玩家可以从全部护符词条中随机获得 5 个不重复选项：没有护符时自动获得护符，有一个词条时自动放入第二槽，已有两个词条时选择替换其中一个。超时或放弃选择时，该奖励失效。

### 图片输出

安装 Puppeteer 后，插件会将以下内容渲染为图片：

- 个人战斗名片和装备栏
- 玩家对战结果、双方头像、血条和完整战斗日志
- 探索路线、地图、区域 Boss 和通关庆祝画面
- 装备掉落、护符炼化、批量锻造和 Boss 讨伐

QQ 头像会尝试通过 QQ 头像服务获取；获取失败时使用用户名首字作为占位头像。图片渲染失败时会自动回退为文字消息。

## 配置

常用配置及默认值：

| 配置项 | 默认值 | 说明 |
| --- | ---: | --- |
| `enableImages` | `true` | 是否启用 Puppeteer 图片输出 |
| `exploreDurationSeconds` | `600` | 派遣探索每张地图的推进时间 |
| `dailyExploreLimit` | `3` | 每日探索结算次数上限 |
| `battleCooldownSeconds` | `60` | 玩家对战冷却时间 |
| `bossRaidCooldownSeconds` | `600` | Boss 讨伐冷却时间 |
| `alchemyCost` | `3000` | 单次护符炼化消耗 |
| `forgeCost` | `1000` | 单次装备锻造消耗 |
| `equipmentDropRate` | `42` | 对战装备掉落概率（百分比） |
| `itemUseRate` | `42` | 战斗中自动使用道具的概率（百分比） |
| `skillRate` | `30` | 部分武器技能触发概率（百分比） |
| `maxBattleTurns` | `100` | 单场战斗最大回合数 |

## 数据存储

插件使用 Koishi Database，主要数据表为：

- `deadcells_players`：玩家角色、装备、护符、细胞、探索状态和冷却时间。
- `deadcells_daily_bosses`：每日共享 Boss、当前生命值、击杀者和讨伐排行榜。

探索任务和最后一击词条选择状态也会写入玩家数据，因此可以在机器人重启后恢复。

## 开发

安装开发依赖并运行测试：

```bash
npm install
npm run build
npm test
```

图片素材位于 `pic` 目录，TypeScript 源码位于 `src`，编译输出位于 `lib`。
